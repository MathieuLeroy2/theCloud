# Hoofdstuk 5 Zien of je systemen goed werken

**Vast labowachtwoord:** gebruik voor alle accounts in dit hoofdstuk `Student123`. Gebruik dezelfde waarde voor herstelwachtwoorden en SSH-wachtzinnen. Alleen bij een test die bewust moet mislukken vul je een fout wachtwoord in.


Je volgt Linux, Windows en containers op met je eigen Prometheus en Grafana. Je maakt een dashboard en laat waarschuwingen afgaan en herstellen.

## Wat leer je?

1. Exporters op Linux en Windows koppelen.
2. Meetgegevens lokaal met Prometheus bewaren.
3. Host- en containermetingen met juiste labels opvragen.
4. Een dashboard met juiste eenheden maken.
5. Web- en resourcealerts veilig testen en herstellen.

## Materiaal

1. Lees de [theorie](theorie.md).
2. Gebruik de [slides](slides.md) tijdens de les.
3. Voer de [opdrachten](opdrachten.md) uit.
4. Vergelijk je werk waar nodig met de [oplossingen](oplossingen.md).

Vul tijdens het werken [je verslag](bestanden/verslag-sjabloon.md) aan. Je dient alleen **verslag.md** in: instellingen, antwoorden, code en testresultaten staan samen in dat ene bestand. De bestanden om je dienst te laten draaien staan daarnaast gewoon op je VM.

Voorzie ongeveer vijf uur voor het labo, met de voorbereiding uit de opdrachten. Gebruik de adressen en versies die de docent bevestigt. De [infrastructuurgids](../../docenten/infrastructuur.md) beschrijft wat vooraf klaar moet staan. Praktijkcontrole op de concrete lesomgeving blijft nodig.
