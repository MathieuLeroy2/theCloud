# Hoofdstuk 3 Een dienst aanbieden op een server

Je maakt een nieuwe VM vanuit een template. Daarop bied je met Jellyfin een mediadienst aan, bereikbaar via HTTPS vanaf twee clients.

## Wat leer je?

1. Cloudbegrippen aan een concreet voorbeeld koppelen.
2. Een VM uit een template maken met cloud-init.
3. Met een eigen SSH-sleutel aanmelden.
4. Jellyfin met passende leesrechten en accounts instellen.
5. HTTPS en toegang vanaf twee clients testen.

## Materiaal

1. Lees de [theorie](theorie.md).
2. Gebruik de [slides](slides.md) tijdens de les.
3. Voer de [opdrachten](opdrachten.md) uit.
4. Vergelijk je werk waar nodig met de [oplossingen](oplossingen.md).

Vul tijdens het werken [je verslag](bestanden/verslag-sjabloon.md) aan. Je dient alleen **verslag.md** in: instellingen, antwoorden, code en testresultaten staan samen in dat ene bestand. De bestanden om je dienst te laten draaien staan daarnaast gewoon op je VM.

Voorzie ongeveer vier uur voor het labo, met de voorbereiding uit de opdrachten. Gebruik de adressen en versies die de docent bevestigt. De [infrastructuurgids](../../docenten/infrastructuur.md) beschrijft wat vooraf klaar moet staan. Praktijkcontrole op de concrete lesomgeving blijft nodig.
