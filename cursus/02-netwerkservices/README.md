# Hoofdstuk 2 Eén account voor meerdere computers

**Vast labowachtwoord:** gebruik voor alle accounts in dit hoofdstuk `Student123`. Gebruik dezelfde waarde voor herstelwachtwoorden en SSH-wachtzinnen. Alleen bij een test die bewust moet mislukken vul je een fout wachtwoord in.


Je bouwt een Windows-domein met een server en twee pc’s. Je test wie waar mag aanmelden en hoe je die toegang centraal regelt.

## Wat leer je?

1. Een Windows-server en twee clients in Proxmox klaarzetten.
2. DNS en een domein instellen.
3. Gebruikers, groepen en OU’s maken.
4. Toegang via de console en RDP regelen met een GPO.
5. Toegelaten en geweigerde aanmeldingen testen en een DNS-fout herstellen.

## Materiaal

1. Lees de [theorie](theorie.md).
2. Gebruik de [slides](slides.md) tijdens de les.
3. Voer de [opdrachten](opdrachten.md) uit.
4. Vergelijk je werk waar nodig met de [oplossingen](oplossingen.md).

Vul tijdens het werken [je verslag](bestanden/verslag-sjabloon.md) aan. Je dient alleen **verslag.md** in: instellingen, antwoorden, code en testresultaten staan samen in dat ene bestand. De bestanden om je dienst te laten draaien staan daarnaast gewoon op je VM.

Voorzie ongeveer 4,5 uur voor het labo, met de voorbereiding uit de opdrachten. Gebruik de adressen en versies die de docent bevestigt. De [infrastructuurgids](../../docenten/infrastructuur.md) beschrijft wat vooraf klaar moet staan. Praktijkcontrole op de concrete lesomgeving blijft nodig.
