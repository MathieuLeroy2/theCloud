Mijn IoT-werkplek

Deze pagina draait op mijn eigen virtuele Ubuntu Server.

Het project

Ik werk aan een meetopstelling voor het binnenklimaat van een lokaal. Sensoren meten temperatuur en luchtvochtigheid. Later wil ik die waarden via een broker naar een dashboard sturen.

Mijn infrastructuur

  • Proxmox beheert mijn virtuele machines.
  • Ubuntu Server biedt deze website aan via NGINX.
  • Xubuntu is de client waarmee ik de werking controleer.

Herstelcontrole

Deze zin hoort bij de oorspronkelijke website.
