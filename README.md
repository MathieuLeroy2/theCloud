# The Cloud

Cursus voor het tweede jaar graduaat Internet of Things. Je leert virtuele infrastructuur opbouwen, diensten aanbieden en hun werking opvolgen. De labo's gebruiken eigen infrastructuur of infrastructuur van de opleiding. Een commerciële cloudaccount of kredietkaart is niet nodig.

**Vast labowachtwoord: `Student123`.** Dit geldt voor alle laboaccounts, herstelwachtwoorden en SSH-wachtzinnen. Alleen bij een test die een verkeerde aanmelding moet aantonen, gebruik je bewust een fout wachtwoord.

De [inhoudelijke analyse en het cursusvoorstel](CURSUSVOORSTEL.md) beschrijven de herwerking. `base/` bevat het oorspronkelijke materiaal en wordt niet aangepast. Deze map is lokaal beschikbaar en wordt door de bestaande `.gitignore` uitgesloten van versiebeheer.

Studenten dienen per labo of test **één `verslag.md`** in. Ook hun instellingen, code en testresultaten staan in dat bestand. Er is geen aparte labkaart. De cursusbestanden blijven per hoofdstuk gegroepeerd. De volledige cursus is inhoudelijk uitgewerkt; zie de [validatiestatus](docenten/versies.md) voor het onderscheid tussen gecontroleerde voorbeelden en nog uit te voeren tests op de lesomgeving.
