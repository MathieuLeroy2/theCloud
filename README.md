# The Cloud

Cursus voor het tweede jaar graduaat Internet of Things. Je leert virtuele infrastructuur opbouwen, diensten aanbieden en hun werking opvolgen. De labo's gebruiken eigen infrastructuur of infrastructuur van de opleiding. Een commerciële cloudaccount of kredietkaart is niet nodig.

## Starten

Lees eerst de [startgids](cursus/00-start/README.md). Elk inhoudelijk hoofdstuk bundelt theorie, Marp-slides, opdrachten, oplossingen en ondersteunende bestanden.

| Hoofdstuk | Status |
| --- | --- |
| [01 Hypervisors en virtuele infrastructuur](cursus/01-hypervisors/README.md) | Eerste volledige uitwerking; praktijkvalidatie op de lesinfrastructuur nog nodig |
| 02 Netwerkservices en centraal toegangsbeheer | Gepland |
| 03 Cloudprincipes en diensten aanbieden | Gepland |
| 04 Containers en een IoT-toepassing | Gepland |
| 05 Monitoring, dashboards en foutdetectie | Gepland |
| 06 Geïntegreerde praktijktest | Gepland |

De [inhoudelijke analyse en het cursusvoorstel](CURSUSVOORSTEL.md) beschrijven de herwerking. `base/` bevat het oorspronkelijke materiaal en wordt niet aangepast. Deze map is lokaal beschikbaar en wordt door de bestaande `.gitignore` uitgesloten van versiebeheer.
